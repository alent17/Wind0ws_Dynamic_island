# 原生 UI 逐页复刻记录

更新：2026-09-28。目标是旧版现有界面的 1:1 复刻；以下是阶段记录，不代表全量验收。

## 本轮实现

- 从已安装的 lucide-svelte 提取 20 个原版 SVG，Direct2D 直接绘制；随构建附带原许可。生成脚本为 `scripts/sync-native-icons.mjs`。
- 对齐工具栏、详情标题、返回按钮、内容边距、音量与倒计时刻度、固定宽度数字、时间日期、天气当前值及三日预报的位置和字体。
- 倒计时恢复 20 分钟默认值、1–1440 分钟刻度、启动/暂停/继续/取消及完成卡片；状态独立于可见页面。收起态显示剩余时间和进度。
- 设备菜单叠加在现有尺寸内，展开箭头翻转，支持按像素滚动及边缘部分行；绘制裁剪与点击区域使用同一视口。
- 修正横向滚轮方向，工具栏支持 Home/End。数字读数使用原版固定数字槽尺寸，尚未迁移滚动数字动画。
- 新增隔离的 `--test-fixture` 数据与 `--test-taskbar` 检查入口。测试数据不启动真实音量、媒体、频谱或天气服务；设备选择只改测试状态。
- 构建时跳过内容未变的字体复制，避免正在运行的测试实例占用字体文件导致重复构建失败。

## 参考与验证方法

`ui-tests/native-parity.pw.ts` 渲染生产 Svelte 组件、MiSans 和固定数据，记录 8 个状态截图及真实 DOM 布局。输出位于被 Git 忽略的 `native/artifacts/parity/`。这项测试生成旧版参考，不是自动断言新旧像素一致。

原生 Release 测试使用独立配置，固定左侧 `DISPLAY2`。本轮实际点击验证音量拖动、设备选择、工具栏滚动、时间/天气切换，以及倒计时启动、暂停、空白收起、自动完成与关闭提示返回音乐页。没有修改真实系统音量或输出设备。桌面截图包含用户桌面内容，不提交。

检查：Rust 58 项通过，1 项联网封面测试按默认忽略；Clippy `-D warnings` 通过；Svelte 检查 0 错误、0 警告；参考截图测试通过；原生 Release 构建通过。本轮未重新执行旧 Python 桌面自动化脚本，也未重新测量性能。
