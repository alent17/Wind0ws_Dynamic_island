# M3 封面处理回归修正

实验开始于 2026-10-09，正式候选 B 六轮及独立诊断于 2026-10-10 完成。M3 预算保护、匹配 Release C 回归门槛、三档 renderer DPR 画质及重开验收通过，勾选 `[x]`。M2 保持 `[x]`，M4 和后续阶段未实施；GPU 长期回稳、B0 完整基线及实际 Windows 跨屏 DPI 仍待验证。

## 修正与成本证据

合规静态 JPEG/PNG 保留原编码及 MIME，仍执行完整有界解码；超尺寸、其他格式、APNG 继续使用受限单帧 PNG。普通 Canvas 保留不超过 1280 edge 的源栅格，避免先缩小再由 compositor 缩放。像素模式的 visible×DPR/nearest-neighbor 路径不变。下载、解码、并发、缓存及非法输入保护保留。

101 份冻结输入的独立原生诊断中，统一 PNG 转码与保留原字节的三轮耗时中位数分别为 7.400 秒和 1.625 秒；输出合计 170,855,819 → 74,714,453 bytes。该结果定位不必要编码的成本，不能证明 Renderer 保留或泄漏的根因。候选 B 正式轮记录 505/506/504 次有界解码、每轮零次编码；codec wall duration 不等同 CPU 时间，也未计入浏览器解码。

候选 A 使用 2×visible×DPR 栅格，恢复 Tree +5.46%、Renderer +13.56%，未通过门槛，因此弃用，完整结果保留于 [CANDIDATE_A.md](CANDIDATE_A.md)。候选 B 保留有界源栅格后重新采集完整六轮，不混用 A 的控制数据。

## 验收边界

三档 renderer DPR 1/1.5/2 前后各 100 首完成，实际采集值与请求 DPR 一致，显示源解码像素每档 100/100 完全一致。实际 Canvas 截图完全一致数分别为 99/100/99，最大 MSE 分别为 0.0000097924/0/0.0000049228；1.5 和 2 的截图尺寸为 276×276、368×368。检查差异最大的样本未见新增软化，Detached Canvas 在各档五次快照中均为零，页面错误为零。详见 [DPR 汇总](dpi-quality-summary.json) 及各档比较 JSON/截图。

两侧各 100 首、每 25 首关闭重开共四次的独立回归通过，封面像素检查全部通过，无空白/错图或 Detached Canvas。该检查使用三点像素或内部 RMS≤8 的跨源截图相似度判定；它与前后逐像素画质比较分开，不能把相似度判定称为全像素相同。

诊断排除记录见 [excluded-diagnostics.json](excluded-diagnostics.json)：旧 Playwright 截图会复位外部 DPR，因此旧 1.5/2 批次排除；改用持有 CDP session 的截图并逐次断言，重跑两档。首个有效 DPR 2 参考轮在第 31 首图片未就绪，缓存完整且独立解码成功，根因未确认；全新配对重跑通过，保留失败记录，不放宽原断言。DPR emulation 覆盖 WebView2 呈现和 M3 栅格逻辑，不代替 Windows 实际跨屏缩放或命中测试。

工程复核：53 Rust 测试通过、1 硬件用例忽略；80 前端测试通过；Svelte 0 errors/0 warnings；9 UI 回归通过；前后 Release 构建成功。当前终端复核 Rust 时先遇到 RC.EXE 路径缺失，补 Windows SDK 路径后全套通过。播放器原 1966 首队列、原曲目与循环模式已恢复，播放状态为 Playing。本阶段独立提交后停止。

GPU 长期回稳仍未证实，五分钟恢复和较低峰值不能证明长期无泄漏。Body 的 HD 源不可用，保持原 108×108 SMTC 缩略图；本轮没有将它计为高清质量样本。原始源 URL 有重复，回放使用 101 个键；此实验不外推真实在线缓存命中率。

下载/解码缓冲计数只覆盖声明的作用域，不含 decoder scratch 和浏览器图片分配；codec 时间是 wall duration；绘制时间戳是原生收到完成事件，非 compositor 实际呈现。原始堆快照、播放器完整队列和用户设置留在本地，不上传。
