# M5 异步资源销毁验收

**结论：M5 通过并勾选。** 延迟监听、图片成功/失败/超时/Abort 清理、动画中卸载及双 rAF 取消均有回归覆盖。匹配 Release 下，各执行 10 次预热和 100 次副窗开关；关闭后的 DOM 与监听器没有净增长，候选版的句柄增长显著低于基线。私有提交仍有增长，因此本报告不宣称内存已经回稳或证明不存在长期增长。

## 测试条件

- 两个隔离数据目录中的 Release 构建：基线 `0f48301` 与仅包含 M5 工作的候选源码；相同 Rust/Cargo 锁文件、Windows/WebView2、窗口配置、低活动设置、测试脚本及 CDP 采样方式。二进制 SHA-256：基线 `55dc41505a43665effac43f4ce97a8949580ab0ad8a05b6b3ca5e65b00a1650d`；候选 `d02cfb6935c58d3085984f955fc8a0f0cf72e4b8c59899f8d5b6a944ec3f82b3`。
- 浮窗关闭后采集主 WebView DOM、JS listener 与强制 GC 后 heap；同时采集 Tauri + WebView2 进程树私有提交、句柄和线程。正式这一轮无活动媒体会话，图片网络请求为 0；实际图片成功/失败/超时/Abort 路径由单元测试覆盖。
- 结果为生命周期诊断对照，不含 GPU、帧时、真实播放器图片请求或长时间内存稳定性结论。

## 100 次开关结果

| 关闭后指标（恢复等待 10 秒） | 基线 | M5 候选 | 观察 |
|---|---:|---:|---|
| DOM Nodes 净变化 | 0 | 0 | 无净增长 |
| JS EventListeners 净变化 | 0 | 0 | 无净增长 |
| 强制 GC 后 JS heap 净变化 | +102,856 B | +108,440 B | 两边均约 +0.1 MiB |
| 进程树句柄净变化 | +612 | +69 | 候选少增 543（约 88.7%）；候选增量集中在前 10 次测量开关，之后平台；基线继续逐步增加 |
| 进程树线程净变化 | −18 | −12 | 两边均未增长 |
| 进程树 Private Bytes 净变化 | +31,834,112 B | +26,546,176 B | 候选少增约 5.0 MiB，但仍有明显绝对增长，不能称为回稳 |

按逐点样本，候选句柄数在 20 次测量开关后约 4,000，至第 100 次仍为 4,006；基线从约 3,982 上升至 4,600。候选关闭态 Nodes/Listeners 始终分别为 1,056/56；偶发打开态波动在关闭后归零。私有提交在两构建中都呈增长，10 秒恢复窗口不足以判断其来源或长期趋势。

## 回归与检查

- `EventManager` mock 延迟 `listen()` 完成，销毁后迟到的 unlisten 只执行一次且监听数归零。
- 图片 helper 覆盖 load、error、timeout、Abort 和晚到回调；Spectrum 取色超时回归覆盖清理。
- Playwright 覆盖 WAAPI enter/exit 中卸载，以及 RollingDigit 在首个或第二个 rAF 后卸载。
- `npm run test`：95 tests passed（20 files）；`npm run check`：0 errors、0 warnings；生命周期 Playwright：4 passed。前端生产构建和 Windows Release 构建均成功。
- 正式开关轮未复现“第 6 首图片超时”。M4 诊断记录中的该现象仍未定位；再次复现时需保留图片错误、请求开始/结束时间与 URL 身份信息，不推断根因。

## 验收边界

M5 的监听、图片请求和动画等待销毁路径已通过相应回归；100 次开关中 DOM/监听器稳定，候选句柄增长趋势明显改善。Private Bytes 仍增长约 25 MiB，需在后续正式长时性能轮继续观察。GPU 回稳、真实播放器连续切歌图片请求、长期稳定性及 B0 基线仍未完成；不纳入 M5 的成功声明。
