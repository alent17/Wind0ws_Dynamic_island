# Isle v1.0.1

- 修正频谱增益顺序，减少高频柱持续顶满；静音时归零，采集断开后自动重试，不同刷新率下保持一致的动画速度。
- 播放器关闭后清除旧媒体状态，恢复时间与天气界面。
- 修正重复 SMTC 快照导致进度停滞的问题，允许暂停时跳转和回到开头；拖动后短暂保护目标进度，播放器拒绝跳转时恢复原位置。
- 移除设置页的“媒体场景”区域。
- 功能区时钟采用漫画风格粗体数字、倾斜排版、暖橙色错位阴影和日期纸条。
- 设置页预览显示当前时间，并随窗口宽度缩放。

验证：41 项前端测试、26 项 Rust 测试通过；Svelte/TypeScript 检查无错误、无警告。各播放器的跳转能力仍取决于其 Windows SMTC 支持。

下载 `Isle_1.0.1_x64-setup.exe` 安装。`SHA256SUMS` 提供安装包完整性校验。
