# Isle — Windows 灵动岛（Tauri）

这个仓库维护基于 **Svelte、Tauri 2 和 WebView2** 的 Windows 桌面应用。独立 Rust/Win32 原生 UI 已迁移到另一个仓库：[Wind0ws_Dynamic_island-native](https://github.com/alent17/Wind0ws_Dynamic_island-native)。

## 开发

需要 Node.js、pnpm（或 npm）、Rust MSVC、Visual Studio C++ Build Tools 和 Windows SDK。

```powershell
pnpm install
pnpm dev
```

常用命令：

```powershell
pnpm check
pnpm test
pnpm test:ui
pnpm build
pnpm bundle:windows
```

`pnpm tauri dev` 可直接启动 Tauri 开发模式。Windows 安装包由 `pnpm bundle:windows` 生成。

## 项目结构

- `src/`：Svelte 界面
- `src-tauri/`：Tauri/Rust 后端与应用配置
- `ui-tests/`：Playwright UI 测试与迁移参考截图
- `docs/`：项目文档、发布记录和 Tauri 性能采样

安装和升级说明见 [INSTALL.md](INSTALL.md)。原生 UI 的源码和文档见[原生 UI 仓库](https://github.com/alent17/Wind0ws_Dynamic_island-native)。

## 连接网易云音乐

默认使用原有「网易云直连（CDP）」方案，提供真实进度、喜欢状态、进度拖动和播放模式控制。在设置中点击「连接播放器」完成首次配置。正在运行但未携带调试参数的网易云需要手动重启连接一次；调试接口无法在已运行的进程中补开。

连接后开启「自动维护网易云连接」：Isle 启动时和发现新的网易云媒体会话时自动核对启动入口，并每 30 秒轻量检查已记录的快捷方式、相关目录及程序文件元数据；检测到变化才运行完整修复。更新覆盖连接参数或替换程序文件后可自动补回参数，无需再次逐个修改快捷方式。参数未变的快捷方式不重复保存；保存的安装路径仅作后备，优先使用当前运行进程、系统注册和普通快捷方式提供的路径。

自动维护不会启动或重启网易云，也不打断播放。若更新已经启动了一个没有调试参数的进程，自动修复只能保证下次启动入口；当前进程仍需点击「连接播放器」手动重新连接一次。临时断连交由有界采样器重试，不触发反复重启。

从灵动岛打开网易云时会补齐启动入口，直接携带本机连接参数运行播放器；已有播放器不被强制结束。只有用户明确点击连接按钮，才允许为开启接口重启。配置保留其他启动参数、URL／文件占位符及原有开机自启选择；注册表修改前保存原值。受保护的公共快捷方式无法改写时，保留当前用户的对应入口。

「检测连接」只读检测并核对绑定；「配置普通启动入口」修复入口但不启动或重启播放器。标准连接保留为受限备用选项，只使用网易云实际向 Windows 上报的能力，不配置入口或读取 CDP；本机 3.1.42.205594 未上报真实时间线、随机和循环能力，也没有标准爱心字段，因此完整功能应使用 CDP。

爱心读取真实喜欢状态，点击前刷新歌曲身份，操作后读回确认；切歌重新读取，初次读取失败最多重试两次。面板重新展开复用已确认状态；播放模式按连接缓存，断连清除。播放／暂停、上一首、下一首由 GSMTC 执行。进度和模式操作拒绝过期的媒体快照，并核对结果，失败不会显示为成功。断连时回退可用系统能力，未知状态不会显示成未喜欢或顺序播放。

真实进度播放中每 200 毫秒、暂停中每 500 毫秒采样，一次最多一个请求；失败退避至最多 5 秒。计时估算使用已确认的进度锚点，以「≈」标识，不启动周期采样。连接模式、进度模式和自动维护开关分别保存；明确选择的标准连接不会被自动覆盖。

如果系统将网易云显示为 `Microsoft.AutoGenerated…`，可在「播放器」中选择「设为网易云」。支持能力、实测限制及回归验证见 [网易云连接验证记录](docs/netease-connection.md)。

### MSIX 通知版本

Windows 通知监听需要具有包身份的安装版本。安装 Windows SDK 和 WebView2 运行时后，使用 `powershell -ExecutionPolicy Bypass -File scripts/build-msix.ps1 -Publisher 'CN=证书主体' -CertificatePath '证书.pfx'` 构建并签名 MSIX；如证书有密码，可通过 `-CertificatePassword` 指定。发布者必须与证书主体完全一致，证书须受目标机器信任。省略证书参数会生成不可直接安装的未签名包。现有 NSIS 打包流程不变。
