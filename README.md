# Isle — Windows 灵动岛（Tauri）

这个仓库维护基于 **Svelte、Tauri 2 和 WebView2** 的 Windows 桌面应用。独立 Rust/Win32 原生 UI 已迁移到另一个仓库：[Wind0ws_Dynamic_island-native](https://github.com/alent17/Wind0ws_Dynamic_island-native)。

## 开发

需要 Node.js、pnpm（或 npm）、Rust MSVC、Visual Studio C++ Build Tools 和 Windows SDK。

```powershell
pnpm install
pnpm dev
```

常用命令：

```powershell
pnpm check
pnpm test
pnpm test:ui
pnpm build
pnpm bundle:windows
```

`pnpm tauri dev` 可直接启动 Tauri 开发模式。Windows 安装包由 `pnpm bundle:windows` 生成。

## 项目结构

- `src/`：Svelte 界面
- `src-tauri/`：Tauri/Rust 后端与应用配置
- `ui-tests/`：Playwright UI 测试与迁移参考截图
- `docs/`：项目文档、发布记录和 Tauri 性能采样

安装和升级说明见 [INSTALL.md](INSTALL.md)。原生 UI 的源码和文档见[原生 UI 仓库](https://github.com/alent17/Wind0ws_Dynamic_island-native)。

## 连接网易云音乐

所有播放器的播放/暂停、上一首、下一首均通过 Windows SMTC 控制。网易云的真实进度、拖拽和播放模式使用专用本机连接；其他播放器的进度拖拽、随机播放及循环模式切换均使用 SMTC。主岛与浮窗只为声明支持相应能力的播放器显示模式按钮，状态以播放器实际快照为准，不支持或拒绝请求时不会视为成功。

在 Isle 设置的「连接网易云音乐」中首次点击「连接并绑定」。该操作自动定位播放器、创建桌面快捷方式 `NetEase Music (Isle)`，并为现有的个人桌面、开始菜单和任务栏网易云快捷方式补齐连接参数，保留其他启动参数。连接已开启时直接复用，未运行时启动；只有手动连接且正在运行的播放器尚未开启连接参数时，才需要重启一次并中断播放。随后核对媒体会话和歌曲，保存绑定与安装路径、选中该播放器并启用真实进度；无需复制其他电脑的路径或会话 ID。以后可以使用已更新的普通快捷方式启动。未找到播放器时，先安装并打开网易云再重试。

首次配置会启用「启动时自动恢复网易云连接」；旧版已保存的网易云绑定也会自动迁移启用，无需再次绑定。灵动岛启动后，以及后来检测到新的网易云媒体会话时，在后台恢复：连接正常时复用，自动恢复不会重启网易云，未运行时不会启动它；没有额外的周期进程扫描。会话 ID 因启动方式变化时重新核对并保存，同时保留播放器优先级、勾选状态和用户选择的进度来源。可在设置中关闭启动恢复。受系统保护而无法写入的快捷方式保持原样，可使用专用快捷方式。

「检测并绑定」不会重启播放器，会核对并保存本机绑定。连接需要客户端支持本机调试接口；配置已保存但未连通、未播放普通歌曲或有多个匹配会话时，不会猜测绑定。请等待客户端加载并播放普通歌曲后重试。连接成功后可使用真实进度和播放模式控制。

爱心读取网易云当前歌曲的真实喜欢状态，已喜欢显示实心红心，点击可添加或取消喜欢。重新展开面板复用已确认状态，不做周期轮询；切歌重新读取，初次读取失败最多重试两次。点击操作会刷新歌曲身份并确认结果，兼容系统媒体信息只返回合作歌曲主歌手的情况。播放模式按连接保留，不因展开面板或切歌重复检测。

如果 Windows 将网易云显示为 `Microsoft.AutoGenerated…`，在设置的「播放器」中点击该会话旁的「设为网易云」。选择按完整会话 ID 保存，名称和后端进度控制会同步修正；「恢复自动识别」可撤销。此操作只识别播放器，连接仍需完成上面的配置。

真实进度独立于普通媒体轮询调度：每次成功读取后，播放中间隔 200 毫秒、暂停中间隔 500 毫秒再次采样；成功采样与拖拽确认立即发送，不受普通进度事件节流影响。切歌或播放状态改变会安排立即重采，旧曲目或旧操作的迟到结果被丢弃。一次最多一个采样请求，单次进度读取的超时上限为 1 秒；失败从 250 毫秒开始重试，连续失败才逐步退避至最多 5 秒，成功后恢复正常频率。本机连接关闭 Nagle 延迟，避免小型 CDP 请求等待前一包确认。计时估算模式不启动周期采样。以上为调度间隔，实际同步延迟还包含播放器响应时间，后台读取频率较旧版提高。
